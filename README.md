# CABGO – Cab Booking App

## Project Description
CABGO is a cab booking application that helps users book a cab by entering their pickup and drop locations and selecting a suitable vehicle.

## Objectives
- Provide a simple cab booking interface.
- Allow users to enter pickup and drop locations.
- Display available cab types.
- Show estimated fare and booking details.
- Provide booking confirmation.

## User Roles
- **Customer:** Books a cab and views booking details.
- **Driver:** Receives and manages booking requests.
- **Administrator:** Manages users, drivers, and bookings.
