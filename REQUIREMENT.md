# CABGO – Software Requirements

## 1. Functional Requirements
- FR1: The system shall allow users to enter pickup and drop locations.
- FR2: The system shall display available cab types.
- FR3: The system shall allow users to select a cab.
- FR4: The system shall estimate the booking fare.
- FR5: The system shall display booking details.
- FR6: The system shall confirm a booking after valid details are submitted.

## 2. Non-Functional Requirements
- NFR1: The interface should be easy to use.
- NFR2: The application should respond quickly.
- NFR3: User information should be protected.
- NFR4: The interface should support desktop and mobile screens.

## 3. Hardware Requirements
- Computer or smartphone
- Internet connection

## 4. Software Requirements
- Windows, Linux, Android, or iOS
- Modern web browser
- Code editor
- Git and GitHub

## 5. Constraints
Live cab tracking, real payments, and driver allocation require backend services and integrations; they are not included in the basic prototype.
