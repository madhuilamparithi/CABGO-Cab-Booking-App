# CABGO – Development Workflow

## Agile Development Process

1. Requirement gathering
2. Product backlog creation
3. Sprint planning
4. Wireframe and prototype design
5. Development
6. Code review
7. Testing
8. Bug fixing
9. Sprint review
10. Release and documentation

## Git Workflow

1. Create a local repository.
2. Create or update project files.
3. Check changes using `git status`.
4. Stage files using `git add .`.
5. Commit changes using `git commit`.
6. Push changes to GitHub.
7. Review the changes in the repository.

## Development Increments

### Increment 1
Deliver the initial booking interface, pickup and drop fields, and cab selection screen.

### Increment 2
Deliver fare estimation, booking confirmation, test cases, and updated documentation.
